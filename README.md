# TTT/CCT Diagram Analyzer

A beginner-friendly Python + Streamlit project for visualizing a simplified CCT diagram and a cooling curve.

## How to run

Open PowerShell inside this folder and run:

```powershell
pip install -r requirements.txt
streamlit run app.py
```

Then open the localhost address shown by Streamlit, usually:

http://localhost:8501

## Important

The CCT transformation data in `data/cct_data.csv` are illustrative placeholders for learning the Python/Streamlit workflow. They are NOT validated AISI 4140 experimental data.

For a final technical/placement project, replace them with reliable published CCT data and cite the source.
